# SpiceNest UI 设计规范

> 本文档定义 SpiceNest 的 UI 设计细节，包括窗口、配色、字体、组件、交互。
> 产品层面的规格见 [SPECIFICATION.md](../SPECIFICATION.md)。
> 与 KeyHub、Nexus 元宇宙保持统一设计语言。

---

## 一、设计原则

### 1.1 核心原则

- **搜索优先**：打开就是搜索框，不搞多级菜单导航
- **查完就走**：内容精炼，卡片一眼看完，不需要滚动翻页
- **可复制**：所有代码、指令、公式都有一键复制按钮
- **键盘友好**：全程键盘操作，不需要鼠标
- **与 Nexus 一致**：窗口样式、交互模式和 KeyHub 保持统一

### 1.2 设计风格

- 现代简约，macOS 原生风格
- 毛玻璃浮动窗口
- 卡片式内容展示
- 柔和的阴影和圆角
- 适度的微动效（hover、点击、切换）
- 琥珀色主题（SpiceNest 品牌色）

## 二、窗口规范

### 2.1 窗口属性

| 属性 | 值 | 说明 |
|------|-----|------|
| 窗口类型 | NSWindow（或 NSPanel） | 浮动窗口 |
| 窗口级别 | .floating | 始终置顶 |
| 背景 | NSVisualEffectView, .material = .popover | 毛玻璃 |
| 圆角 | 12pt | 毛玻璃视图 cornerRadius |
| 标题栏 | 透明，隐藏标题文字 | titlebarAppearsTransparent = true |
| 宽度 | 固定 560pt | minSize.width = maxSize.width = 560 |
| 高度 | 可纵向拉升 | min 400pt, max 3000pt |
| 默认高度 | 640pt | 首次启动 |
| 主题色叠加 | 琥珀色 alpha 0.12 | 毛玻璃上叠加一层半透明颜色 |
| 失去焦点 | 可选自动隐藏 | 用户可设置 |

### 2.2 主题色叠加

```swift
let tintColor = NSColor(red: 1.0, green: 0.584, blue: 0.0, alpha: 0.12)
// #FF9500 with alpha 0.12
```

### 2.3 窗口位置

- 首次启动：屏幕中心
- 后续启动：记住上次位置
- 唤出时：恢复上次位置和大小

## 四、字体系统

### 4.1 字体族

- **中文**：苹方（PingFang SC），系统默认
- **英文/数字**：SF Pro Text，系统默认
- **代码/指令**：SF Mono / Menlo，等宽字体
- **Logo 标题**：Impact（与 KeyHub 一致）

### 4.2 字号层级

| 层级 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| Logo | 28pt | Bold | 34pt | 首页 SpiceNest 标题（Impact） |
| H1 | 20pt | Semibold | 28pt | 详情页卡片标题 |
| H2 | 16pt | Semibold | 22pt | 搜索结果分组标题、卡片内小节标题 |
| Body | 13pt | Regular | 19pt | 正文、说明文字 |
| Small | 11pt | Regular | 16pt | 辅助文字、标签、时间 |
| Code | 12pt | Regular | 18pt | 代码、指令、参数名 |
| Code (大) | 14pt | Regular | 20pt | 卡片中的关键指令 |

## 六、组件规范

### 6.1 搜索框

```
┌─────────────────────────────────────────┐
│ 🔍  搜索指令、参数、报错、公式…          │
└─────────────────────────────────────────┘
```

**属性：**
- 高度：36pt
- 圆角：10pt
- 背景：白色不透明（浅色）/ 深灰不透明（深色）
- 边框：1pt 分隔线色
- 聚焦：边框变琥珀色，阴影 0 0 0 3pt rgba(255,149,0,0.2)
- 左侧：搜索图标（放大镜，16pt，琥珀色），间距 10pt
- 右侧：清除按钮（xmark，输入文字后显示）
- 占位文字：次文字色，"搜索指令、参数、报错、公式…"
- 字体：Body（13pt）

**交互：**
- 打开窗口自动聚焦
- 输入实时搜索（100ms 节流）
- ↑↓ 键在搜索结果中导航
- Enter 打开选中结果
- Esc 清除搜索 / 返回首页 / 关闭窗口

### 6.2 内容卡片（搜索结果用）

```
┌─────────────────────────────────────────┐
│ 📋 .tran — 瞬态仿真                       │
│ 计算电路在指定时间范围内的时域响应          │
│ 语法: .tran tstart tstop [tmax [tstep]] [复制]│
└─────────────────────────────────────────┘
```

**属性：**
- 背景：白色不透明（浅色）/ 深灰不透明（深色）
- 圆角：10pt
- 阴影：0 1pt 4pt rgba(0,0,0,0.06)
- 内边距：14pt
- 悬停：上移 3pt，阴影加深 0 4pt 12pt rgba(0,0,0,0.1)，边框 1pt 琥珀色
- 点击：缩放 0.98

**内容结构：**
- 第一行：类型图标（14pt，类型色）+ 标题（Code 字体 14pt Semibold）+ 中文标题（Body 13pt）
- 第二行：摘要（Small 11pt 次文字色，最多 1 行省略）
- 第三行（可选）：关键信息预览（如语法、公式，Code 字体 12pt）+ 复制按钮

### 6.3 详情卡片（详情页用）

比搜索结果卡片内容更完整，包含所有字段。

**结构（以指令为例）：**
```
┌─────────────────────────────────────────┐
│ 📋 .tran — 瞬态仿真                       │  ← 标题行（图标 + 标题 + 中文名）
│ 计算电路在指定时间范围内的时域响应          │  ← 摘要
├─────────────────────────────────────────┤
│ 语法                                      │  ← 小节标题（H2）
│ .tran <tstop>                            │
│ .tran <tstart> <tstop>                   │
│ ...                                       │
├─────────────────────────────────────────┤
│ 参数说明                                   │
│ tstop  — 仿真停止时间（必填）              │
│ tstart — 开始保存数据的时间（默认 0）       │
│ ...                                       │
├─────────────────────────────────────────┤
│ 示例                                      │
│ ┌─────────────────────────────────────┐ │
│ │ .tran 10m              仿真 0~10ms  │ │  ← 可复制代码块
│ │ .tran 1m 10m           跳过前 1ms   │ │
│ └─────────────────────────────────────┘ │
├─────────────────────────────────────────┤
│ 注意事项                                   │
│ • tmax 设置过小可能导致仿真变慢             │
│ • ...                                     │
├─────────────────────────────────────────┤
│ 相关: .step  .meas  .ic  .options        │  ← 关联内容（可点击跳转）
└─────────────────────────────────────────┘
```

### 6.4 可复制代码块

```
┌─────────────────────────────────────┐
│ .tran 0 10m 1u              [复制]  │
└─────────────────────────────────────┘
```

**属性：**
- 背景：代码块背景色（不透明）
- 圆角：8pt
- 内边距：10pt 12pt
- 字体：SF Mono 12pt
- 右侧：复制按钮（图标按钮，悬停显示）
- 复制成功：按钮变为对勾图标，2秒后恢复
- 多行代码：每行一个复制按钮，或一个"全部复制"按钮

### 6.5 公式计算器

```
┌─────────────────────────────────────────┐
│ RC 低通滤波截止频率                        │
├─────────────────────────────────────────┤
│ R  = [10____] [kΩ ▼]                    │
│ C  = [100___] [nF ▼]                    │
│ ─────────────────────────                  │
│ fc = 159.15 Hz                            │
└─────────────────────────────────────────┘
```

**属性：**
- 背景：卡片背景，边框 1pt 分隔线
- 圆角：10pt
- 内边距：14pt
- 输入框：高度 28pt，圆角 6pt，边框 1pt
- 单位下拉：NSPopUpButton，紧跟输入框
- 结果：大号字体（18pt Semibold），琥珀色
- 结果单位：Small 11pt

### 6.6 标签（Tag）

**类型标签：**
- 高度：20pt
- 圆角：4pt
- 内边距：水平 8pt
- 字体：Small 11pt Medium
- 背景：类型色 + alpha 0.12
- 文字：类型色

**难度标签（拓扑用）：**
- 入门：绿色
- 基础：蓝色
- 进阶：橙色
- 高级：红色

### 6.7 按钮

**文字按钮（操作栏用）：**
- 高度：28pt
- 圆角：6pt
- 内边距：水平 12pt
- 字体：Body 13pt Medium
- 背景：透明
- 悬停：背景悬停色
- 文字：主文字色

**图标按钮：**
- 尺寸：28×28pt
- 圆角：6pt
- 图标：16pt
- 悬停：背景悬停色
- 点击：缩放 0.95

**主要按钮（如"复制全部"）：**
- 背景：琥珀色
- 文字：白色
- 悬停：深琥珀
- 按下：更深琥珀

### 6.8 分组标题

```
📋 仿真指令 (2)
─────────────────────────────────
```

**属性：**
- 字体：H2 16pt Semibold
- 颜色：主文字色
- 左侧：类型图标（14pt，类型色）
- 右侧：数量（Small 11pt 次文字色，括号包裹）
- 底部：分隔线 1pt，或间距 8pt

### 6.9 空状态

```
┌─────────────────────────────────────────┐
│                                         │
│          🔍 没有找到相关内容              │
│                                         │
│     试试其他关键词，或检查拼写是否正确      │
│                                         │
└─────────────────────────────────────────┘
```

**属性：**
- 图标：48pt，次文字色
- 标题：Body 13pt Medium，次文字色
- 建议：Small 11pt，占位文字色
- 垂直居中

## 八、交互规范

### 8.1 鼠标交互

- 可点击元素：鼠标变为手型（.pointingHand）
- 悬停：0.2s 过渡动画（背景、阴影、位移）
- 点击：缩放 0.98，0.1s 过渡
- 卡片悬停：上移 3pt + 阴影加深 + 琥珀色边框

### 8.2 键盘交互

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 唤出/隐藏窗口 | Ctrl+Option+S | 全局热键，可自定义 |
| 聚焦搜索框 | 打开窗口自动聚焦 / Cmd+F | |
| 搜索结果上移 | ↑ | |
| 搜索结果下移 | ↓ | |
| 打开选中结果 | Enter | |
| 返回上一页 | Esc / Backspace | 详情页 → 搜索结果 → 首页 |
| 关闭窗口 | Esc | 首页时按 Esc 关闭窗口 |
| 收藏/取消收藏 | Cmd+D | 详情页 |
| 复制当前卡片 | Cmd+C | 详情页，复制全部可复制内容 |
| 快速分类 1-6 | Cmd+1 ~ Cmd+6 | 首页，切换分类筛选 |

### 8.3 动画

- 页面切换：0.2s 淡入淡出（首页 ↔ 搜索结果 ↔ 详情）
- 悬停效果：0.2s 过渡
- 卡片点击：0.1s 缩放
- 复制成功：按钮图标 0.2s 切换为对勾，2s 后恢复
- 避免过度动画，保持流畅

### 8.4 窗口行为

- 唤出窗口：自动聚焦搜索框，选中上次搜索文本（如有）
- 失去焦点：可选自动隐藏（默认关闭，用户可在设置中开启）
- 点击窗口外：不自动关闭（避免误触），除非用户开启了"失去焦点自动隐藏"
- 窗口大小：记住上次的高度和位置

## 九、图标规范

### 9.1 图标风格

- 使用 SF Symbol（苹果系统图标）
- 线宽：默认（.medium）
- 尺寸：14pt（卡片内）/ 16pt（按钮）/ 18pt（导航）/ 48pt（空状态）
- 颜色：类型色（分组标题）或继承文字色
- 菜单栏图标：SF Symbol `bolt`（闪电），isTemplate = true，14pt

## 十、深色模式

### 10.1 适配原则

- 所有颜色都有深色模式对应值
- 卡片背景用不透明深色（避免毛玻璃上的半透明卡片导致字体模糊）
- 代码块在深色模式下使用深色背景
- 对比度不低于 WCAG AA 标准（4.5:1）
- 跟随系统设置（默认），不提供手动切换（保持简单）

### 10.2 毛玻璃适配

- 深色模式下毛玻璃自动变暗（系统处理）
- 主题色叠加层 alpha 保持 0.12，颜色不变
- 卡片用不透明背景，避免毛玻璃透过来导致对比度不足

## 十一、可访问性

### 11.1 对比度

- 正文文字与背景对比度 ≥ 4.5:1
- 大文字（≥18pt）对比度 ≥ 3:1
- 非文字元素（图标、边框）对比度 ≥ 3:1

### 11.2 键盘导航

- 所有可交互元素可通过 Tab 聚焦
- 聚焦状态清晰可见（2pt 琥珀色边框或系统焦点环）
- 支持快捷键操作（见 8.2）

### 11.3 屏幕阅读器

- 所有图标按钮有 accessibilityLabel
- 卡片有 accessibilityRole（.button）
- 搜索结果列表有 accessibilityLabel
- 关联内容链接有 accessibilityLabel
