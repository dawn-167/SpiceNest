# Changelog

All notable changes to SpiceNest will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2026-08-27

### Added
- Initial release based on Nexus template
- Menu bar status item with bolt icon and Nexus apps submenu
- Global hotkey (Ctrl+Option+S) to toggle window
- URL Scheme support (`nexus-spicenest://`)
- Floating frosted-glass window with amber tint
